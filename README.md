# Image Editor App
## Description
A simple image editor app that allows users to apply basic filters and adjustments to images.

## Features
- Apply filters (grayscale, sepia, invert)
- Adjust brightness and contrast
- Apply random colors to the image

## Technologies
- Frontend: React, HTML/CSS
- Backend: Node.js

## How to Run
- Clone the repository: `git clone https://github.com/username/image-editor-app.git`
- Install dependencies: `npm install`
- Start the app: `npm start`

## Project Structure
- `public/`: static assets (images, styles)
- `src/`: app code (components, containers, utils)
- `src/components/`: React components
- `src/utils/`: utility functions
- `server.js`: Node.js server

## Future Improvements
- Add support for more image filters and adjustments
- Implement user authentication for saving edited images
- Improve performance and optimize for larger images
